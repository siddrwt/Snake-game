# Snake Game

A simple browser-based Snake Game built with HTML, CSS, and JavaScript.

## Features

- Classic snake gameplay
- Score tracking
- High score saved in localStorage
- Timer for elapsed gameplay time
- Restart and game-over flow
- Keyboard controls with direction lock to prevent instant reversal

## How to Run

1. Open the `snake-game` folder.
2. Open `index.html` in a browser.
3. Click the Start Game button.

You can also use a local web server such as Live Server in VS Code for a smoother experience.

## Controls

- Arrow Up: move up
- Arrow Down: move down
- Arrow Left: move left
- Arrow Right: move right

## Game Rules

- Eat the food to increase your score.
- Each food item adds 10 points.
- Avoid hitting the walls.
- Avoid hitting your own body.
- The game ends when collision occurs.

## Files

- `index.html` — game layout
- `style.css` — styling for the board and UI
- `script.js` — gameplay logic and interactions

## Notes

This is a beginner-friendly project intended for learning JavaScript DOM and game logic.
